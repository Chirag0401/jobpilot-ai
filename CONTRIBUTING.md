# Contributing to JobPilot AI

Thanks for helping people discover better opportunities! Please keep changes simple and privacy-minded.

1. Fork and clone the project.
2. Create a new branch: `git checkout -b feature/your-idea`.
3. Install dev dependencies: `pip install -r requirements-dev.txt`.
4. Run the offline test suite: `pytest -q`.
5. Open a pull request explaining what changed and how you tested it.

**Please do not include** real API keys, resumes, applicant contact information, or personal employment records. Do not add CAPTCHA bypass or silent application submission. New job-board connectors should respect public APIs, rate limits, and platform terms.
